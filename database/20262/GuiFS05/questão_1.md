## Q1. Banco de Dados e SGBD

Banco de Dados (BD) é uma coleção organizada de dados relacionados, armazenados de forma estruturada para permitir seu acesso, consulta, alteração e gerenciamento.
Sistema Gerenciador de Banco de Dados (SGBD) é o software responsável por criar, armazenar, consultar, atualizar e controlar o acesso aos dados de um banco de dados, além de garantir propriedades como segurança, integridade e recuperação.

Exemplos:

Banco de Dados	SGBD
Banco de dados de uma loja	MySQL
Banco de dados de um sistema bancário	PostgreSQL
Banco de dados de uma empresa	Oracle Database
Banco de dados de uma aplicação web	Microsoft SQL Server
Banco de dados de documentos	MongoDB
