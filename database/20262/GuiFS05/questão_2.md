## Q2. Sistemas de Arquivos

O uso de arquivos para armazenar dados apresenta diversos problemas:

Redundância: os mesmos dados podem ser armazenados em vários arquivos.
Inconsistência: uma informação pode ser alterada em um arquivo e permanecer desatualizada em outro.
Dificuldade de acesso: consultas e relacionamentos entre dados precisam ser programados manualmente.
Problemas de concorrência: vários usuários podem modificar os mesmos dados simultaneamente, causando conflitos.
Baixa segurança: o controle de acesso aos dados é mais limitado.
Dificuldade de recuperação: falhas podem causar perda ou corrupção de dados.
Falta de integridade: é mais difícil garantir que os dados obedeçam às regras do sistema.
