Todo projeto deve estar obrigatoriamente associado a um cliente cadastrado e existente no banco de dados.

Todo funcionário deve estar alocado obrigatoriamente a uma squad válida e existente.

Toda sprint deve pertencer obrigatoriamente a uma squad existente que seja responsável por sua execução.

Toda tarefa deve estar obrigatoriamente vinculada a um projeto existente, a uma sprint válida e a uma squad responsável.

Toda release deve estar associada a um cliente existente e planejada por uma squad válida.

Todo teste de validação deve pertencer obrigatoriamente a uma release existente.

Na tabela associativa entre release e tarefa, cada registro deve referenciar obrigatoriamente uma release válida e uma tarefa existente.

Toda squad deve possuir obrigatoriamente ao menos um membro com o papel de líder técnico registrado.
