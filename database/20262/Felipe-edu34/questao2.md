**Q2.** Quais os principais problemas de utilizar Sistemas de Arquivos para armazenagem de dados?



O uso de sistemas de arquivos tradicionais para o armazenamento de dados apresenta limitações estruturais significativas em comparação aos Sistemas Gerenciadores de Bancos de Dados, sendo os principais problemas a redundância e a inconsistência de dados, causadas pela duplicação de informações idênticas em vários arquivos que podem ser atualizados de forma descompassada. Além disso, há uma grande dificuldade de acesso aos dados, pois os sistemas de arquivos não oferecem ferramentas flexíveis para consultas dinâmicas, exigindo códigos complexos para extrair informações cruzadas. Outro ponto crítico é o isolamento de dados, uma vez que as informações ficam espalhadas em formatos diferentes, dificultando a integração para uma visão unificada. O acesso concorrente também é problemático, pois sem um controle nativo, múltiplos usuários modificando o mesmo arquivo simultaneamente podem causar perda ou corrupção de dados. A segurança também fica comprometida, visto que o controle de permissões costuma ser restrito ao arquivo inteiro no nível do sistema operacional, e não de forma granular a colunas ou campos específicos. Por fim, a falta de integridade e atomicidade obriga que regras de negócio e transações seguras — onde um conjunto de operações deve ocorrer por completo ou ser totalmente revertido — sejam programadas manualmente pelo desenvolvedor em cada aplicação, aumentando consideravelmente a margem para falhas.
